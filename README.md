# Proview QR Menu & Loyalty

Resellable restaurant app: stamp card and rewards, menu, table booking and "What's on", with a master console for managing every client site.

- **Live:** https://testqr.proviewcrm.co.uk
- **Client site link:** `https://testqr.proviewcrm.co.uk/#<site-link-name>` (for example `#harbour-smoke`)
- **Master console:** "View all sites" in the top bar, or "Master login" in the footer.
  First sign-in: `master` / `changeme`. Change it in Settings → Master login straight away.

Pushing to `main` redeploys through GitHub Pages.

## Note
Sites and the master login are saved in the browser that edits them. Use Settings → Backup to move them to another computer.
